# LabLog

研究室（大学）に来た時刻・出た時刻・滞在時間と、PC でどんな作業をしたかを自動で記録するアプリです。
記録はこの PC の中に保存します。iPhone・iPad で見るために OneDrive へ書き出すのは要約だけです（下の「iPhone・iPad で見る」）。

## 使い始める

1. PowerShell でこのフォルダの `install_autostart.ps1` を実行します。
   ログオン時に自動で起動するようになり、ダッシュボード（`http://127.0.0.1:8765/`）がブラウザで開きます。
   ```
   powershell -ExecutionPolicy Bypass -File install_autostart.ps1
   ```
2. ダッシュボードの **設定** で次の 2 つを済ませます。
   - **Wi-Fi の登録**：研究室にいるときに「研究室として登録」を押します。研究室専用と大学共通の Wi-Fi（ScienceTokyo など）は、つながっているときにそれぞれ登録してください。自宅では「自宅として登録」を押します。iPhone のテザリングのように大学でも大学の外でも使う Wi-Fi は「判定に使わない」にします（登録していない Wi-Fi は「大学の外」とみなされ、つないだ時点で退出が確定します）。
   - eduroam や Wi2 は他の場所にもあるので「大学」には登録しないでください（他大学やカフェでも「大学にいる」と記録されます）。
   - **監視するフォルダ**：「フォルダを選んで追加…」から、研究のファイルや Git リポジトリを置いているフォルダを追加します。中にある Git リポジトリも自動で見つけます。
3. （任意）日報を文章で要約したい場合は、下の「ローカルAI」を設定します。

あとから開くときは、スタートメニューの **LabLog** を開くか、`LabLog.pyw` をダブルクリックします（起動中ならダッシュボードが開くだけです）。

## 入退室の判定

| きっかけ | 判定 |
|---|---|
| 「大学」として登録した Wi-Fi につながる | 入室（仮退出中なら取り消して滞在を続ける） |
| Wi-Fi が切れる（スリープ・シャットダウンを含む） | 仮退出 |
| 大学の外の Wi-Fi につながる | 仮退出した時刻で退出確定 |
| 仮退出のまま 4 時間たつ | 仮退出した時刻で退出確定 |
| 大学の Wi-Fi のまま 4 時間操作がない | 最後に操作した時刻で退出確定 |
| 「判定に使わない」に登録した Wi-Fi（iPhone のテザリングなど）につながる | 直前の状態を続ける（在室中なら滞在を続け、仮退出中なら仮退出のまま） |

- **滞在時間**は、PC を閉じてゼミに出ていた時間（仮退出から戻るまで）も含みます。
- **PC作業時間**は、5 分以上操作がなかった時間（離席）を除きます。大学・自宅・その他に分けて集計します。
- 1 日は朝 5 時で区切ります。深夜の作業は前日分です。夜通しいた場合も 1 回の滞在として記録します。
- 判定がずれたときは、日別画面の「入退室の記録」から時刻を直したり、追加・削除したりできます。
- 4 時間・5 分などの時間は設定で変えられます。

## 記録するもの

| 材料 | 内容 |
|---|---|
| ウィンドウ | 前面にあるアプリ名とウィンドウ名、使っていた時間（5 秒ごとに確認） |
| ファイル | 監視フォルダ内で作成・保存・削除・名前変更したファイル（パス・時刻・サイズだけ。中身は読まない） |
| Git | 監視フォルダ内のリポジトリのコミット、未コミットの変更数 |
| ブラウザ履歴 | Chrome・Edge で開いたページの URL とタイトル（シークレット／InPrivate は対象外）。画面に表示したページだけを表示・日報に使い、開いたままのタブがバックグラウンドで読み込まれただけのものは除きます |
| 最近使ったファイル | Windows の「最近使ったファイル」の一覧 |
| Claude Code の会話 | 会話の題名・作業フォルダ・やりとりした時刻（分単位）。ウィンドウ名が「Claude」だけのときに、この題名で補います。会話の中身は記録しません |
| 画面の文字 | 対象のアプリ（初期設定は Claude・ChatGPT・To Do・Teams・Zoom・MATLAB・ターミナル・PowerShell。ウィンドウ名から作業内容が分からないもの）が前面にあるとき、5 分に 1 回そのウィンドウだけを写し、Windows 標準の文字認識で文字にしたもの。画像は保存せず、文字は 3 日で消します。OneDrive には書き出しません |

- 上部の **■（記録を一時停止）** を押すと、作業内容の記録（上の表のすべて）を止めます。入退室の判定は続けます。止めている間は **▶（記録を再開）** に変わります。
- 画面の文字の読み取りは、2 分以上操作していないときや「記録しないアプリ」でも行いません。読み取った文字は日別画面の「画面から読み取った文字」で確かめられ、設定の「ウィンドウ名から分からない作業」でまとめて消せます。
- 設定の **記録しないアプリ** に入れたアプリは、時間だけを「(除外)」として残し、名前とウィンドウ名は記録しません。
- 分類（コーディング・解析／文書・資料作成 など）のルールは設定で変えられ、過去の記録にも反映されます。

## コミットの通知

監視フォルダ内のリポジトリで、ファイルを編集しているのに 2 時間以上コミットしていないと、Windows の通知で知らせます。
一度知らせたら、同じ時間がたつまで再通知しません。時間と通知のオン・オフは設定で変えられます。

## 日報

退出が確定したときと、日付が変わったときに、その日の記録から日報の下書きを自動で作ります。
日別画面で書き直して「保存」すると、自動では上書きしなくなります。

- ローカルAI が無いとき：集計から箇条書きの下書きを作ります。
- ローカルAI があるとき：記録を要約して文章の下書きを作ります（このPCで 40〜60 秒ほど）。
  メール・ファイル整理・分類できなかったサイト（動画など）・中身の分からないウィンドウは、AI に渡す前に除いています。

### ローカルAI（Ollama）の設定

1. Ollama をインストールします：`winget install Ollama.Ollama`（または https://ollama.com から）
2. モデルをダウンロードします（約 5GB）：`ollama pull qwen3:8b`
3. ダッシュボードの設定で「準備完了」と表示されれば使えます。別のモデルを使うときはモデル名を変えます。

LabLog は `127.0.0.1`（この PC）の Ollama にしか接続しません。PC 外の URL は設定できないようにしてあり、プロキシも使いません。
Wi-Fi を切った状態でも日報を作れるので、外部に送っていないことを確かめられます。

## 画面の演出

その日の作業時間に応じて、ページの背景（壁紙）とカードが少しずつ豪華になります。この度合いを「フロー」と呼び、日別画面の「研究室・PC作業時間」のタイルの右上に 4 つの目盛りで出します。触れる（マウスを重ねる）と、フローが深まるまでの時間が出ます。

| フロー | 目安（PC作業時間。大学にいた時間の 75% のほうが長ければそちら） | 見た目 |
|---|---|---|
| 0 | 1 時間未満 | 灰色の地に白いカード（地味） |
| 1 | 1 時間〜 | 背景にうっすら青い光 |
| 2 | 3 時間〜 | 青・緑・紫の光、カードがすりガラスに |
| 3 | 5 時間〜 | 青・紫・ピンク・オレンジの光、数値のタイルに光る縁取り（研究室・PC作業時間のタイルは半透明のまま） |
| 4 | 7 時間〜 | いちばん鮮やかな光がゆっくり動く |

- 月の画面は、作業した日の平均でフローが決まります。設定画面はいつもフロー 0 です。
- タイムラインや分類別の色は意味を持つので変えません。
- 見た目を確かめるときは、URL に `?level=4` を付けるとフローを固定できます（例：`http://127.0.0.1:8765/?level=4`）。
- 日報は罫線入りのノート風に、手書き風の文字で表示します。文字は Klee One（SIL Open Font License 1.1。`lablog/web/fonts/OFL.txt`）を日本語の常用範囲に絞って同梱しています。

## iPhone・iPad で見る

PC と同じ画面を、iPhone・iPad の Safari で開けるビューアーがあります（`https://kkosugitm.github.io/lablog/`）。
Safari の共有ボタン →「ホーム画面に追加」で、アプリと同じようにアイコンから開けます。

- **しくみ**：PC の LabLog が要約を OneDrive のアプリ専用フォルダ（`OneDrive\アプリ\LabLog`）に書き出し、ビューアーは個人の Microsoft アカウントでサインインしてそれを読みます。ビューアーが触れるのはこのフォルダだけです。
- **OneDrive に置くもの**：入退室・滞在時間・PC作業時間（大学／自宅）・分類別の時間・タイムラインの分類・日報。
- **PC だけに残すもの**：ウィンドウ名、閲覧したページ、編集・使用したファイル、Git、Wi-Fi 名。記録そのもの（`lablog.db`）も OneDrive には置きません。
- **書き出すタイミング**：5 分ごと（変わった分だけ）と、入退室・日報の作成・保存・滞在の修正のとき。設定の「今すぐ書き出す」でもすぐ書き出せます。
- **iPhone・iPad で直す**：日報の書き直しと滞在の追加・修正・削除ができます。直した内容は OneDrive の `edits` に置かれ、PC の LabLog が次に動いたとき（30 秒ごとに確認）に取り込みます。それまでは「PC へ反映待ち」と表示します。
- **始め方**：ビューアーを開いてサインインすると、OneDrive に `アプリ\LabLog` フォルダができます。PC の LabLog は目印の `viewer.json` を見つけると（数分以内）、書き出しを始めます。
- 書き出しを止めたいときは、設定の「iPhone・iPad で見る」で「OneDrive に書き出す」を外します。

## データの保存場所

`%LOCALAPPDATA%\LabLog`（OneDrive の外なので、クラウドには同期されません）

| ファイル | 内容 |
|---|---|
| `lablog.db` | 記録（SQLite） |
| `settings.json` | 設定 |
| `lablog.log` | 動作ログ（困ったときに見る） |

月ごとの入退室は、月画面の「CSV で書き出す」から Excel で開ける形式で保存できます。
ダッシュボードは `127.0.0.1` だけで待ち受けるので、同じ Wi-Fi の他の人からは開けません。

## 困ったとき

- **Wi-Fi が「未接続」のままになる**：Windows の設定 → プライバシーとセキュリティ → 位置情報 で「デスクトップアプリに位置情報へのアクセスを許可する」をオンにしてください（Windows の仕様で、Wi-Fi 名の取得に必要な場合があります）。
- **ダッシュボードが開かない**：ポート 8765 を他のアプリが使っている可能性があります。`settings.json` の `port` を変えて、LabLog を起動し直してください。
- **自動起動をやめたい**：`uninstall_autostart.ps1` を実行します（記録データは残ります）。

## 開発者向け

- Python 3.11 以降の標準ライブラリだけで動きます（追加のインストールは不要）。
- テスト：`python -m unittest tests.test_presence tests.test_cloud`
- 本番のデータと分けて試すとき：`python LabLog.pyw --port 8766 --data-dir <テスト用フォルダ>`
- ビューアーを PC で試すとき：`python tools/preview_viewer.py`（いまの記録の写しを使い、サインインなしで `http://127.0.0.1:8770/` に開く）
- ビューアーを公開し直すとき：`python tools/publish_viewer.py --push`（`lablog/web` の画面ファイルを `..\lablog-viewer` に写して GitHub の gh-pages ブランチに送る。記録は含めない）
